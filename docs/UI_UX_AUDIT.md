# UI 디자인·UX 라이팅 감사

- 감사일: 2026-07-31
- 범위: 오늘, 학습, 복습, 연습 타이머, 기록, 큐브 촬영, 설정, 앱 아이콘
- 기준 기기: iPhone 17 Pro, iPhone 13 mini, iPhone SE 3세대 시뮬레이터, iOS 26.5, 세로 화면
- 확인 조건: 라이트·다크 모드, 기본 큰 글자 크기, iPhone 13 mini Accessibility Medium 스트레스 점검, 소스·접근성 라벨 검토

## 결론

이번 검수의 핵심 문제는 기능 부족보다 **화면마다 달랐던 제품 언어와 증거 수준**이었다. `학습`, `복습`, `연습`의 역할을 다시 고정하고, 사용자가 직접 확인한 기록을 `검증·숙달·완료`처럼 과장하지 않도록 고쳤다. 연습 화면은 스크롤과 추가 화면 없이 스크램블, 섞은 상태 확인, 타이머를 한 화면에 유지했다.

앱 아이콘은 자동 해결 앱처럼 보이던 순환 화살표·체크·그라디언트에 이어 면색, 스티커 격자와 회전 레이어 강조도 제거했다. 새 아이콘은 Harbour Blue 바탕과 단색 와이어 큐브만 남겨 작은 크기에서도 제품 종류를 즉시 알아보게 한다.

## 이번에 반영한 변경

### 1. 제품 언어 통일

- 탭과 화면 이름은 `오늘`, `학습`, `연습`, `기록`으로 고정했다.
- 타이머 모드는 `자유 연습`, `15초 인스펙션`으로 통일했다.
- `공식`은 동작열, `케이스·패턴`은 시각 상태, `솔브`는 측정한 한 번의 시도로 구분했다.
- `Trainer`, `detector`, `cubie`, `parity` 같은 구현 용어를 사용자 문장에서 제거하거나 쉬운 한국어로 바꿨다.
- 학습 열람이나 수동 비교를 `숙달·검증·완료`로 부르지 않고 `복습 기록`으로 표현했다.
- 촬영 흐름은 `내 큐브 확인 → 상태 확인 → 추천 연습`으로 통일했다.
- 전체 저장 기록으로 계산하는 값은 `세션 평균`이 아니라 `전체 평균`으로 바로잡았다.
- `초급·중급`이라는 보편 등급을 제거하고 `레이어 해법 기초`, `2-Look CFOP 시작`처럼 학습 범위를 직접 표시했다.
- 검출 후보 수 대신 `확인 필요한 칸 N개`처럼 다음 행동에 필요한 정보만 표시했다.

### 2. 행동 중심 UX 라이팅

대표 변경:

- `오늘 이어서 할 일` → `오늘 할 일`
- `확인한 공식` → `복습 기록이 있는 공식`
- `연습 시작` → `타이머 연습`
- `공식 학습` → `학습`
- `WCA 방식 연습` → `15초 인스펙션`
- `검산 기준` → `섞은 상태 확인`
- `다 돌렸어요` → `돌리기 완료`
- `기대 결과` → `목표 상태`
- `이 상태의 케이스는 무엇인가요?` → `이 패턴은 어떤 케이스인가요?`
- `스크램블을 확인하고 바로 기록하세요.` → `스크램블 확인 후 바로 시작해요.`
- `‘손을 떼어 시작’이 보이면 놓으세요.` → `버튼이 초록색이면 놓으세요.`

설명은 한 문장에 한 행동만 담고, 본문은 판단하지 않는 해요체로 통일했다. 버튼은 사용자가 누른 뒤 일어나는 결과가 보이도록 동사형으로 작성했다.

### 3. 시각 체계 정리

- 브랜드 강조색을 인디고에서 Malta-informed `Harbour Blue`로 교체했다. 밝은 화면 `#075E79`, 어두운 화면 `#0B7896`과 별도 고대비 변형을 사용한다.
- 키 컬러는 주요 행동·선택 상태에만 쓰고, 석회암색은 앱 아이콘의 보조 재료색으로만 제한해 관광 앱처럼 보이지 않게 했다.
- 페이지와 카드의 시스템 grouped 배경을 분리해 라이트·다크 모드 계층을 유지했다.
- 카드 기본 여백과 반경을 18pt로 맞추고, 장식 그림자 대신 얇은 테두리를 사용했다.
- 연습 타이머의 주요 버튼, 탭 선택, 스캔 진입점이 같은 브랜드 색을 사용하도록 정리했다.
- 큐브 여섯 색은 상태 도식에만 사용하고 일반 버튼 의미 색으로 확장하지 않았다.

### 3-1. 내 큐브 확인 진입 재기획

- 연습 화면 우상단의 의미가 불분명한 `viewfinder`를 `camera.viewfinder`로 교체했다.
- 첫 화면에서 `촬영해서 채우기`와 `전개도에 직접 입력`을 함께 보여 주고, 큰 글자에서는 같은 화면을 스크롤할 수 있게 했다.
- 직접 입력을 고르면 촬영 없이 센터 6칸이 고정된 54칸 전개도로 이동한다.
- 촬영 화면에서는 탭 바·내비게이션 바·카드·스크롤을 제거하고 전체 화면 프리뷰로 전환한다.
- 상단에는 닫기, `1/6`부터 `6/6`까지의 진행 상태와 현재 촬영 면만 남겼다.
- 하단에는 촬영 면·위쪽 인접 면 안내, 원형 셔터와 `직접 입력`만 두어 피사체보다 UI가 강해지지 않게 했다.

### 3-2. 기기 폭·타이머 집중 모드

- iPhone 17 Pro와 iPhone 13 mini에서 오늘·학습·연습·기록·내 큐브 확인·카메라 대체 화면을 각각 캡처해 잘림과 줄바꿈을 점검했다.
- iPhone 13 mini에서 오늘 화면의 타이머 CTA가 세 줄로 갈라지던 문장을 한 줄로 줄였다.
- 기록 화면의 두 줄 각주가 다음 `시간 추세` 헤더와 겹치지 않도록 세로 고정 크기를 보장했다.
- 타이머가 실제로 시작되면 스크램블·전개도·모드·내비게이션을 숨기고 검은 전체 화면에 시간과 정지 안내만 표시한다.
- 실행 중 첫 touch-down 정지는 화면 전체에서 유지되며, 17 Pro와 13 mini 모두 실행 화면에서 스크램블이 사라지는 것을 확인했다.

### 3-3. 앱 내부 화면 모드

- 오늘 화면의 톱니바퀴 진입 이름을 `설정`으로 넓혀 실제 화면 범위와 맞췄다.
- 설정 첫 항목에서 `시스템`, `라이트`, `다크`를 별도 깊이 없이 바로 선택할 수 있다.
- 선택은 즉시 앱 전체에 적용되고 재실행 뒤에도 기기에 유지된다.
- 기본값 `시스템`은 iPhone의 화면 모드를 따르며, 모든 로컬 데이터 삭제 시 화면 모드도 기본값으로 돌아간다.

### 3-4. 학습 문구와 공식 표기

- 학습 첫 설명을 `그림을 보고 따라 돌리기 → 공식 없이 복습하기` 두 행동으로 나눴다.
- 해법 내부 문장은 한 문장에 한 행동만 남기고, 긴 보조 설명은 짧은 행으로 분리했다.
- 긴 전체 공식은 줄바꿈하지 않고 가로 스크롤로 표시해 기호 중간이 잘리지 않게 했다.
- 공식 카드와 단계 버튼에서는 회전 방향 문장을 제거하고 `R U R' U'` 같은 표준 기호만 표시한다.
- `R`, `R'`, `R2`의 뜻과 방향 화살표는 학습 첫 화면의 `기호 읽는 법`으로 모았다.
- 별표는 표준 공식 표기가 아니므로 사용하지 않는다. 내부 파서와 학습 UI 모두 WCA Article 12의 아포스트로피를 유지한다.
- 설정의 개인정보·삭제 안내를 짧은 행으로 나누고, 가변 본문 높이를 보장해 좁은 화면에서도 문장 중간이 잘리지 않게 했다.
- iPhone 17 Pro와 iPhone 13 mini의 학습 첫 화면에서 새 문구가 잘리지 않고 카드 폭 안에 놓이는 것을 확인했다(`/tmp/cubecoach-copy-notation-shots/iphone-17-pro-learn.png`, `/tmp/cubecoach-copy-notation-shots/iphone-13-mini-learn.png`).

### 4. 앱 아이콘 재설계

- 제거: 순환 화살표, 완료 체크, 광택, 그라디언트, 면색, 3×3 스티커 격자, 회전 레이어 강조.
- 유지: 작은 크기에서도 식별되는 단색 와이어 큐브.
- 색상: Harbour Blue 배경과 미색 마크 한 색만 사용한다.
- 자산: 기본·다크·틴트 1024×1024 PNG.
- 재현 도구: `Tools/generate_app_icons.swift`.

## 남은 우선순위

### P0 — 배포 전 필수

1. 실제 iPhone에서 여섯 면 정면 촬영, 색상 인식, 54칸 복원·면별 재촬영·수정, 상태 진단을 검증한다.
2. 실제 iPhone에서 전체 화면 타이머 정지가 첫 touch-down에 동작하는지 반복 측정한다.
3. VoiceOver, 더 큰 텍스트, 대비 증가, 동작 줄이기, 색상 없이 구분을 실기기에서 확인한다.
4. App Store 제출용 실제 서명 Archive와 개인정보·권한 문구를 최종 검증한다.

### P1 — 다음 디자인 패스

1. 복습 화면의 카드 수와 보조 설명을 더 줄여 현재 단계와 다음 행동만 남긴다.
2. 기록 첫 화면은 최고 기록, 전체 평균, Ao5/Ao12를 우선하고 완주율·기록 편차는 다음 계층으로 묶는다.
3. 촬영 오버레이를 다양한 조명·스티커리스 큐브에서 검증하고 재촬영보다 수정할 칸을 먼저 제시한다.
4. 큐브 전개도의 문자·테두리 대비와 색각 보조 패턴을 사용자 테스트한다.

### P2 — 데이터 이후 판단

1. 복습 성공률, 도움 사용량, 타이머 재시도 흐름을 관찰해 오늘 화면의 추천 우선순위를 조정한다.
2. 아이콘의 단색 와이어 큐브가 60pt·App Store 검색 결과 맥락에서 충분히 구별되는지 확인한다.

## 검증 한계

시뮬레이터에서 iPhone 17 Pro·13 mini·SE 3세대의 주요 탭과 무스크롤 타이머 배치를 확인했다. 스캔 화면의 소형 기기·Dynamic Type 조정은 진행 중이므로 최종 레이아웃 수치를 확정하지 않는다. 로컬 Xcode의 시뮬레이터 프레임워크는 빌드 가능한 상태이고 개발 팀으로 서명한 generic iOS 빌드도 성공했다. 최신 개발 빌드는 iPhone 13 mini에 설치했지만 iOS의 개발자 프로파일 신뢰가 완료되지 않아 자동 실행이 차단됐다. 사용자 신뢰 후 라이브 카메라·햅틱·첫 touch-down 지연·VoiceOver를 검증해야 한다.
