CubeCoach 개인정보 처리방침

시행일: 2026년 7월 31일

CubeCoach는 큐브 공식 암기와 솔빙 연습을 돕는 iOS 앱입니다. 이 문서는 현재 앱이 데이터를 처리하는 방식을 알기 쉽게 설명합니다.

1. 수집하거나 전송하는 데이터

CubeCoach는 계정, 광고 또는 분석 SDK를 사용하지 않으며, 사용자의 개인정보와 앱 기록을 개발자 서버로 수집하거나 전송하지 않습니다.

2. 카메라 이미지 처리

카메라는 사용자가 큐브 촬영 기능을 직접 시작한 경우에만 권한을 요청합니다. 라이브 프레임과 촬영 이미지는 큐브 촬영 및 인식 기능을 위해 기기 안에서 일시적으로 처리됩니다. 앱은 해당 이미지나 영상을 사진 앱, 앱 파일 또는 서버에 저장하거나 전송하지 않습니다. 카메라 권한을 거부해도 수동 확인과 다른 학습·타이머 기능을 사용할 수 있습니다.

3. 기기에 저장되는 데이터

학습 진행, 솔브 및 타이머 기록, 복습 횟수와 일일 목표는 앱의 로컬 저장소에만 저장됩니다. 계정이나 클라우드 동기화 기능은 제공하지 않습니다.

4. 데이터 삭제

앱의 오늘 → 개인정보 및 데이터 → 모든 로컬 데이터 삭제에서 학습 진행, 솔브 기록, 복습 횟수, 일일 목표와 손상 데이터 복구용 사본을 삭제할 수 있습니다. 삭제한 데이터는 복구할 수 없습니다. 앱을 삭제하면 iOS가 앱의 로컬 컨테이너도 제거합니다.

5. 제3자 제공 및 추적

CubeCoach는 사용자 데이터를 제3자에게 판매하거나 제공하지 않으며, 다른 회사의 앱이나 웹사이트를 넘나드는 추적을 하지 않습니다. 공개 웹 링크를 열면 해당 웹사이트의 정책이 적용될 수 있습니다.

6. 변경 사항

데이터 처리 방식이 변경되면 앱의 동작과 App Store 개인정보 공개 내용을 함께 검토하고 이 페이지의 내용과 시행일을 갱신합니다.

7. 문의

개인정보 처리 또는 삭제에 관한 문의는 GitHub Issues에 남길 수 있습니다. 공개 이슈에 사진, 기록 또는 그 밖의 개인정보를 첨부하지 마세요.

이 문서는 앱의 실제 데이터 처리 방식을 설명하기 위한 것이며 법률 자문이 아닙니다.
