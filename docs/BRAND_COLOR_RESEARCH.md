# Malta-informed 브랜드 컬러 리서치

- 조사일: 2026-07-31
- 결정: 단일 키 컬러는 `Harbour Blue`
- 범위: 앱 강조색, 선택 상태, 주요 행동, 앱 아이콘

## 결론

Malta의 국기나 관광 포스터를 직접 모사하지 않는다. Malta의 시각적 인상을 만드는 **깊은 지중해색과 따뜻한 석회암의 대비**만 추출한다.

앱의 키 컬러는 밝은 화면 `#075E79`, 어두운 화면 `#0B7896`이다. 흰색 버튼 라벨과 각각 약 7.28:1, 5.07:1 대비를 가지며 Apple이 일반 텍스트에 안내하는 4.5:1 기준을 넘는다. 고대비 모드에는 더 짙은 밝은 화면 변형과 더 밝은 어두운 화면 변형을 별도로 둔다.

## 사용 원칙

1. `Harbour Blue`는 다음 주요 행동, 선택된 탭, 활성 제어에만 쓴다.
2. 실행 중 타이머는 검정과 흰색을 유지한다. 집중 상태를 브랜드색으로 채우지 않는다.
3. 큐브 여섯 색은 상태 정보다. 브랜드 팔레트와 섞거나 재착색하지 않는다.
4. 성공·경고·삭제는 iOS 의미 색과 아이콘·문장을 함께 사용한다.
5. 석회암색은 앱 아이콘의 단색 마크처럼 작은 보조 영역에만 사용한다.

## 제외한 방향

- Malta 국기 빨강 `#CF142B`: 큐브 R면과 오류·삭제 의미에 충돌한다.
- 흰색/빨강 양분, George Cross, Maltese Cross: 공식 상징 또는 제휴로 오인될 수 있다.
- 밝은 아쿠아 그라디언트와 luzzu 다색 조합: 큐브 스티커보다 강하고 관광 앱 인상을 만든다.
- `공식 Malta 컬러`, `VisitMalta 제휴` 같은 표현: 사실이 아니므로 사용하지 않는다.
